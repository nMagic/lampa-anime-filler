# Lampa Anime Filler

Экспериментальный плагин для Lampa: цветные метки эпизодов по классификации филлеров. **Версия 0.3.0 — только маркировка** (без автоматического пропуска). Маркировка One Piece 52–58 подтверждена в Online_Mod на реальном LG webOS. BWA, Samsung Tizen и Android TV ещё требуют проверки на устройствах.

## Исправления версии 0.3.0

- **One Piece (1999) / Ван-Пис** теперь определяется по проверенному TMDB ID `37854`. Раньше японское и русское названия не совпадали с англоязычным каталогом, из-за чего плагин не загружал данные.
- Добавлен тест распознавания сериалов с локализованными названиями.

### Исправления версии 0.2.1

- Исправлена ошибка настроек Lampa `Cannot read properties of undefined (reading '')`: для двух текстовых полей зарегистрирован тип значений, необходимый `SettingsApi`.
- Исправлено чтение значения переключателя «Помечать серии» (`'false'` теперь отключает маркировку).
- Добавлен автоматический smoke-тест страницы настроек.

## Изменения v0.3.0 и проверка на телевизоре

После сообщений об отсутствии меток в Online_Mod и BWA:

- Расширен поиск строк: в BWA Prestige используются `.online-prestige` и `.online-prestige__title`, а не только старые селекторы.
- Добавлен перехват `Lampa.Template.get` для шаблонов `online_mod`, `online`, `lampac_prestige_full`: он сохраняет **исходные структурированные номера эпизодов**, даже когда вместо номера показано название серии.
- Добавлено распознавание названия вида `55 серия`, ранее работало только `Серия 55`.
- Для **One Piece** подтверждённый **первый сезон** может использовать смещение ноль. Остальные сезоны без проверенных смещений не размечаются, чтобы не перепутать сквозную и сезонную нумерацию.
- В настройках добавлена кнопка **«Показать диагностику»**. В отчёте видны сопоставление названия, состояние загрузки, количество эпизодов в каталоге, захваченные шаблоны и метки.

### Проверка

1. Удалить старый плагин и установить заново по прежней прямой ссылке `https://nmagic.github.io/lampa-anime-filler/a.js`, перезапустить Lampa.
2. Открыть One Piece (1999), перейти к сериям первого сезона (например, 54–60), попробовать Online_Mod и BWA.
3. Вернуться в **Настройки → Anime Filler → Показать диагностику**, сделать фото отчёта.

Online_Mod подтверждён на LG webOS для One Piece 52–58. Совместимость BWA пока основана на анализе шаблона и автоматическом тесте; её необходимо подтвердить на реальном устройстве.

## Установка в Lampa

**Используйте прямую ссылку на JS-файл (без сокращателя и перенаправлений):**

```text
https://nmagic.github.io/lampa-anime-filler/a.js
```

В Lampa: **Настройки → Расширения / Плагины → Добавить плагин** → вставить URL → перезапустить.

Короткая ссылка `https://is.gd/lampaaf` перенаправляет корректно в обычном HTTP-клиенте, **но в Lampa на телевизоре может выдать статус 404**. Проверка статуса выполняется через XHR и переход на другой домен может блокироваться CORS. Код 404 в интерфейсе Lampa также отображается для сетевых ошибок без HTTP-статуса. Сама GitHub Pages страница возвращает 200 и `Access-Control-Allow-Origin: *`.

Если неудобно вводить длинную ссылку пультом, можно скопировать её на телевизор с телефона через приложение-пульт или добавить URL в профиль CUB для синхронизации плагинов (если такая функция доступна в используемой сборке Lampa).

На LG webOS подтверждён сценарий Online_Mod для One Piece 52–58. Android TV, Samsung Tizen и остальные источники серий ещё не проверены. Это маркировочный прототип v0.3.0; автоматического пропуска нет.

---

Проект независимого плагина для Lampa, рассчитанного на Android TV, LG webOS и Samsung Tizen. Online_Mod проверен на LG webOS; остальные платформы и источники требуют отдельных device tests. Код выполняется в интерфейсе Lampa, а не внутри видеоплеера, поэтому внешние видеоплееры не влияют на саму маркировку.

Целевая архитектура, правила безопасного сопоставления и порядок внедрения автоматического пропуска описаны в [`docs/architecture.md`](docs/architecture.md). Контракт versioned data bundle проверяется отдельно и пока не меняет подтверждённый runtime v0.3.0.

## Что сделано

- Плагин помечает распознанные **эпизоды в списках** (часть разметки Lampa `online`, `torrent-file`, `full-episode` и некоторые альтернативные элементы) на основе классификации канона и филлеров.
- Цветные метки: красная «Ф · Филлер», жёлтая «С · Канон + филлер», зелёная «М · Манга-канон», синяя «А · Аниме-канон». Для запасного набора данных `Canon` отображается зелёная «К · Канон».
- При переходе между аниме старые метки удаляются.
- Номер эпизода извлекается из некоторых распространённых форматов: `Серия 26`, `Episode 26`, `Naruto - 026 [1080p].mkv`, `S02E06` при проверенном соответствии сезонов.
- Если источник записал `S1 / Episode 5` или `S02E06` и соответствие сезонов не указано, метка **не ставится**, чтобы случайно не перепутать номер сезона с абсолютным номером из AnimeFillerList.
- Статус рядом с карточкой сериала показывает количество найденных филлеров и источник данных, если сработала соответствующая разметка.
- Нет изменения плейлиста, автоматического пропуска, удаления торрентов или перехвата плеера: это отдельный последующий этап.

## Откуда берутся данные

1. Приоритет: **подготовленные пользователем JSON-файлы** на собственном HTTPS-хостинге. Пользователь отвечает за право получения и использования исходных данных.
2. Если собственного файла нет: **независимый резервный набор SkipTheFiller**, доступный на GitHub (CC BY 4.0, 45 аниме). Это **не animefillerlist.com**; он может отличаться по типам серий и набору аниме.

Плагин не обходит CORS/защиту сайта, не парсит animefillerlist.com на устройстве и не содержит полной базы AnimeFillerList. Для автоматического обновления требуется отдельное решение по получению данных с учётом правил сайта.

## Установка и тестирование

1. Выложить `lampa-anime-filler.js` на HTTPS, доступный устройству (например, в собственный GitHub Pages). Архив сам по себе **не является URL для установки**.
2. В Lampa зайти в «Настройки → Плагины/Расширения → Добавить» и ввести HTTPS URL этого JS-файла.
3. Перезапустить Lampa и открыть карточку аниме (например, Naruto или Bleach).
4. Открыть список серий у своего онлайн-провайдера или список файлов торрента. Метки появятся только если номер распознан, классификация доступна и разметка этого списка поддерживается.
5. Если серию не пометило — проверить, есть ли она в базе, точно ли определилось название и является ли номер сквозным.

**Важно:** маркировка внутри Online_Mod, BWA, Showy, MODS и прочих модифицированных экранов **не гарантируется** до проверки их фактической разметки. Для исправления понадобится название сборки/плагина и скриншот списка эпизодов или его HTML-структура.

## Пользовательский источник JSON

Репозиторий не содержит скрапера AnimeFillerList. Если у вас есть законно полученная классификация, разместите файлы `slug.json` на собственном HTTPS-хостинге и укажите базовый URL в `Настройки → Anime Filler → Каталог AnimeFillerList JSON (HTTPS)`.

Минимальный формат файла:

```json
{
  "slug": "naruto",
  "episodes": [
    { "number": 1, "type": "Manga Canon" },
    { "number": 26, "type": "Filler" }
  ]
}
```

При несовпадении названия из TMDB со slug заполните поле «Привязки TMDB ID к названию (JSON)», например `{"12345":"naruto"}`.

Пользовательский файл может также содержать `{ "seasonOffsets": { "1": 0, "2": 24 } }` (внутри основного JSON, не отдельно). Такие смещения допустимы **только после ручной проверки**, поскольку TMDB и онлайн-провайдеры часто группируют сезоны по-разному.

Проверяйте условия использования AnimeFillerList до массового сбора данных и публичной публикации.

## Тесты

```bash
node --check lampa-anime-filler.js
node --check a.js
node --test tests/*.test.cjs tests/*.test.mjs
node tests/settings-smoke.cjs
node scripts/build-data.mjs --check
```

Тесты проверяют сопоставление One Piece/Naruto/Naruto Shippuden, абсолютную и сезонную нумерацию, отказ от неоднозначных диапазонов/OVA, структурированные данные Online_Mod/BWA, торрент-файлы, сетевые ошибки и защиту от запоздалого ответа предыдущей карточки. Они **не являются тестами в Lampa, Android TV, webOS или Tizen**.

## Существующие ограничения

- Проверены лишь часть распространённых DOM-классов, не все интерфейсы внешних онлайн-плагинов.
- Нет автоматического определения соответствия сезонов TMDB и абсолютной нумерации.
- Мультисерийные файлы, сезонные архивы без ясных эпизодов и неоднозначные названия намеренно не маркируются.
- Плагину необходим доступ к источнику JSON с устройства (сетевые ограничения на конкретном ТВ могут помешать).
- Для реального испытания нужен HTTPS URL на JS. Архив содержит только исходники.

# Отчёт: Universal Mapping Pipeline и Source-aware Episode Mapper v0.4.1

## 1. Краткое резюме

PR #4 расширен с четырёх вручную описанных аниме до build-time анализа всех 45 произведений каталога. Pipeline получает полные generated mappings AniBridge и anime-offline-database, проверяет закреплённые SHA-256, выполняет точное identity resolution, валидирует episode ranges и генерирует компактный runtime index и два coverage report.

Runtime теперь разделяет два независимых утверждения:

- `providerMappings` описывает доказанное преобразование TMDB/TVDB season+episode в абсолютный номер каталога;
- `sourceBindings` сообщает, что конкретный адаптер/балансер действительно использует эту систему.

Без второго утверждения сезонный payload возвращает `unknown`. Online_Mod теперь диагностируется с точным именем балансера (`online_mod:cdnvideohub`, `online_mod:kodik` и т. п.). Дополнительный generator исследует 102 обнаруженных source entry и выпускает полный [`source-coverage.md`](../../reports/source-coverage.md). Playback Controller и плейлист не менялись, auto-skip не добавлялся.

Для Bleach подтверждены identity TMDB TV `30984` и provider mapping абсолютных эпизодов 1–366. Гипотеза `S2 E1–42 → 367–408` удалена: ни диагностика 372 строк, ни отдельные TYBW entries AniBridge не доказывают такое объединение в классификации SkipTheFiller.

## 3. Источники mappings

### AniBridge

Используется полный release artifact `mappings.min.json`, а не `mappings.edits.yaml`:

- schema `3.0.3`;
- generated `2026-10-22T06:55:54Z`;
- SHA-256 `4e2dd941d4962c0997c30cdb69969eb2249276046f1359f6478348fe74f96cfc`;
- license MIT.

Аудит upstream pipeline подтвердил стадии ID graph, episode graph, inference, overrides, validation/pruning, transitive closure и serialization. `mappings.edits.yaml` содержит только ручные replacement links. `provenance.zip` (SHA-256 `2d03ba9166d78db205d6a81dac63a6becf2db50e836dda17463c5b5c81d93011`) использован для проверки происхождения событий, но не нужен runtime.

### anime-offline-database

Используется release `2026-43`, artifact `anime-offline-database-minified.json`, SHA-256 `1489835bcf9730e718a51c36f758d8bfe1ee2015a146a4449ba27c603aff9367` (ODbL 1.0 / DbCL 1.0). Он предоставляет точные primary/alternative titles, media type, year, episode count и подтверждённые AniDB/AniList/MAL IDs.

### Правила достоверности

- только exact normalized primary/alternative title или exact title+year; fuzzy match не является доказательством;
- только `TV`, фильмы не могут занять TV identity;
- TMDB ID берётся из прямого AniBridge descriptor relationship;
- exact episode count имеет приоритет; при нескольких ID требуется consensus;
- specials (`s0`) не входят в regular mapping;
- конкурирующие range edges разрешаются только строгим consensus, tie исключается;
- generated runtime mapping содержит только единственный TMDB TV ID; partial/ambiguous entries не получают guessed ID;
- `sourceBindings` не наследуется между балансерами или адаптерами.

## 4. Оставшиеся проблемы

Полные причины для каждого из 45 произведений находятся в coverage report. Критические identity-ограничения:

| Произведение | Статус | Причина |
|---|---|---|
| D.Gray-man | partial / unsupported | Каталог объединяет `D.Gray-man` и `D.Gray-man Hallow`, которые имеют TMDB TV 34141 и 67145. Один runtime TMDB identity был бы ложным. |
| Digimon Adventure | ambiguous | Exact-title candidates ведут к TMDB TV 31654 и reboot 98034; 104 эпизода не доказывают композицию. |
| Fist of the North Star | ambiguous | Original и remake дают TMDB TV 56387 и 295357; episode count не разрешает конфликт. |

Ещё 22 title имеют partial episode coverage: identity надёжна, но AniBridge доказывает только prefix или отдельные диапазоны. My Hero Academia имеет verified identity, но нулевое безопасное episode conversion: exact alias candidates начинаются с третьего сезона, поэтому offset не вычисляется сложением сезонов.

One Piece имеет 1156 из 1173 проверенных преобразований в закреплённом AniBridge snapshot; последние 17 остаются unknown. Bleach имеет 366 из 408; TYBW 367–408 unknown. Конфликты между AniDB и AniList/MAL representations фиксируются в JSON и не скрываются общей цифрой.

## 5. Результаты тестов

Выполнен 41 автоматический тест Node.js и отдельный settings smoke test; все проходят.

Проверяются:

- весь каталог 45/9552 и пересчёт каждой summary statistic;
- отсутствие пропущенных произведений и наличие результата resolution;
- границы, уникальность и provenance каждого опубликованного provider range;
- Bleach, One Piece, Naruto и Naruto Shippuden, включая границы сезонов и unknown ranges;
- absolute, reset и continuous numbering basis;
- разные Online_Mod balancers и неизвестный adapter;
- полный реестр 102 sources, его статусы, статистика и generated report;
- автоматическое обнаружение добавленного Online_Mod balancer и запрет binding без basis;
- exact localized aliases, похожие titles и TV/movie collision;
- partial ranges, overlap/tie conflicts, invalid IDs, specials/OVA;
- отсутствие/повреждение external database и изменение AniBridge mapping;
- schema-v1 Data Provider, SHA-256, validated cache и legacy fallback.

CI выполняет `build-mappings --verify`, `build-source-inventory --verify` и `build-data --verify`, поэтому stale report, пропущенный title/source или рассинхрон runtime bundle завершают job ошибкой.
